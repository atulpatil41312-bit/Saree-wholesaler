# Asset sources and licensing

## Included assets

- `placeholder-hero.svg` — original abstract woven artwork created for this template. It is a replaceable fallback for shops without a banner image.
- `placeholder-product.svg` — original abstract product placeholder created for this template. It is a replaceable fallback for catalogue items without a product photo.
- `style.css` — original project CSS. It uses system font stacks only; no third-party font files or external font requests are included.

## Reference research

The storefront structure was informed by the public retail patterns observed at `sutisancha.com`, `vastranand.in`, and `suratsarees.in`: layered navigation, category discovery, catalogue filters, and concise product specifications. No logos, names, written copy, product data, proprietary code, or images were copied from those sites.

## Shop-supplied media

The runtime template displays a shop's existing logo, banner, and product images when they are configured. Store owners are responsible for holding the rights to those uploaded assets.
